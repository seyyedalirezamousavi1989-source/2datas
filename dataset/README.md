# Seed dataset

This directory contains a small, authored starter corpus for AURORA QUANT.

- `seed/identity.jsonl`: project/model identity examples.
- `seed/forex_knowledge.jsonl`: foundational domain-knowledge examples.

Each line is one JSON object with a three-message conversation and metadata. See [the seed dataset specification](../../docs/phase-0/INITIAL_CURATED_SEED_DATASET.md).

These files are not a complete or production-approved dataset. They contain no market-price series or trade outcomes. Do not treat them as evidence of trading edge or model performance.
