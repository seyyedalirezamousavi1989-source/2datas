# Provenance schema contracts

These JSON Schema Draft 2020-12 documents formalize the Phase 0 provenance, versioning and reproducibility specification.

- [Artifact manifest](artifact-manifest.schema.json): immutable artifact identity, checksum, parent lineage, rights classification and reproducibility level.
- [Transformation run](transformation-run.schema.json): pinned inputs/outputs, repository commit, configuration checksum, environment, determinism and run status.
- [Dataset build manifest](dataset-build-manifest.schema.json): XAUUSD dataset release identity, component artifacts, independent component versions, rights, validation and immutable-release policy.
- [Chronological split manifest](split-manifest.schema.json): group/episode assignment, UTC boundaries, purge/embargo metadata and frozen status.
- [Sample lineage](sample-lineage.schema.json): per-example input artifact references, point-in-time availability, feature/label versions, split and quality state.

## Validation boundary

Schema validation checks structure and local field constraints. It does **not** prove that hashes match files, parent graphs are acyclic, timestamps are causally valid, split groups do not overlap, licenses permit use, or transformations are reproducible. Those require executable semantic validators and independent evidence.

All schemas are contracts only. No real market data was ingested or generated by adding them. The dataset remains in design/specification status until the relevant project gate is explicitly approved.
